# Night Vault Heist

Top-down stealth heist game in your browser. Move with WASD or arrows, stay
out of guard vision cones, dodge cameras, and grab the loot before the alarm
meter fills. Patrols and multiple vault routes keep every run fresh.

Spend your take on tools — jammer, decoy, or crack kit — each at a cost.
Plan the heist, beat the patrols, and get out clean.
